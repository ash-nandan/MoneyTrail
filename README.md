# MoneyTrail

**Follow Where Your Money Goes!**

MoneyTrail is a personal finance web application I'm building to better understand where my money goes and how my spending changes over time.

The project is currently in development, with the initial homepage completed and the core financial tracking features planned for future development.

## About the Project

MoneyTrail grew from the way I previously tracked my finances manually using Google Sheets.

My spreadsheet allowed me to record my spending, track the remaining balance in my main account, and keep track of balances across my spending and savings accounts. While this system worked, I wanted to challenge myself to turn that manual process into a full-stack web application of my own.

The idea was also partly inspired by watching Caleb Hammer's *Financial Audit* and learning about personal finance applications such as DollarWise.

## Current Progress

MoneyTrail is currently in the early stages of development.

So far, I have:

- Set up the full-stack project structure
- Created the initial application routes
- Built the public homepage
- Started planning the navigation and core application features

## Planned Features

The initial version of MoneyTrail is planned to include:

- User authentication
- Personal finance dashboard
- Transaction tracking
- Current main account balance
- Total balance across accounts
- Adding new transactions
- Viewing individual transactions
- Editing existing transactions
- Deleting transactions

As the project develops, I would also like to explore features such as spending categories, account management, searching and filtering transactions, and visualising financial trends over time.

## Tech Stack

MoneyTrail is being built using:

- React
- TypeScript
- Node.js
- Express
- SQL
- Knex.js
- React Router

The project uses a full-stack boilerplate originally provided through Dev Academy Aotearoa.
